🔍 QR Extension Debug Page

Debug Steps:

1. Extension Status

✅ Make sure the extension is reloaded and enabled in chrome://extensions/

2. Check Console

✅ Press F12 → Console tab

✅ Look for "QR Generator:" messages

3. Expected Behavior

✅ You should see a floating circular logo in the bottom-right corner

✅ Logo should have a gradient background (purple/blue)

✅ Logo should contain the first letter "D" (for Debug)

4. Manual Test

Open Console and run this command:

console.log('Extension loaded:', !!window.QRCode, 'Content script:', !!document.querySelector('.qr-floating-logo'))

Common Issues:

  • No console messages: Content script not loading
  • "QRCode is not defined": Library not loading
  • Console errors: JavaScript errors preventing execution
  • No floating logo: CSS not loading or z-index issues

Quick Fix:

  1. Go to chrome://extensions/
  2. Click "Remove" on QR Code Generator
  3. Click "Load unpacked" again
  4. Select the erweima folder
  5. Refresh this page
